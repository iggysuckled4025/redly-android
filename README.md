## 🛠️ Frequently Asked Questions

**Does this app require an account?**
No. You do not need a Reddit account to view public content.

**Is this software free?**

**Why does my phone show a warning during install?**
Android protects users from software downloaded outside of official stores. Since this project is open-source, it sits in a repository rather than a corporate app store. This triggers a standard safety check.

**Does this work on older versions of Android?**
The app performs best on Android 8.0 and newer. Older versions lack the required background services for the modern web components used to build this client.

**How do I update the application?**
Check the releases page mentioned above. Version numbers indicate updates. When a newer version appears, download the file again. Install it over the existing app. Your settings will persist.

If the app fails to open, check your storage space. If the content fails to load, verify your internet connection. Some Reddit servers experience downtime.
